N&A SCHOOL SUPPLIES POS SYSTEM
================================

REQUIREMENTS (Install these first):
1. XAMPP - https://www.apachefriends.org
2. Node.js - https://nodejs.org (LTS version)
3. N&A School Supplies POS Setup.exe

FIRST TIME SETUP:
1. Install XAMPP
2. Install Node.js
3. Run "N&A School Supplies POS Setup.exe"
4. Open XAMPP Control Panel
5. Start MySQL
6. Open phpMyAdmin (http://localhost/phpmyadmin)
7. Create a database named: na_pos
8. Open Command Prompt in the "server" folder
9. Run: npm install
10. Run: node seed.js (creates admin user)

DAILY USE:
- Double click "start.bat" to launch the system
- Login with your password
- Double click "stop.bat" to shut down

DEFAULT LOGIN:
- Password: admin123
- Change this after first login!
